# 🛡️ Security Policy & Responsible Disclosure

This document outlines the procedures for reporting vulnerabilities and our commitment to the secure engineering of the **Ollama MCP Orchestrator**.

## 🚀 Supported Versions

| Version | Security Support | Status |
| :--- | :--- | :--- |
| **Main (Latest)** | Active | :white_check_mark: Supported |
| **All Previous** | Best Effort | :warning: Unofficial |

## 🔍 Reporting a Vulnerability

If you discover a security vulnerability, please report it **responsibly**. Do **not** open a public issue.

### 📨 How to Report
Please email your detailed report to:
**[mrvishalsinghchauhan01@gmail.com](mailto:mrvishalsinghchauhan01@gmail.com)**

**Please include:**
- Vulnerability description.
- Reproduction steps (PoC).
- Potential impact.
- Suggested mitigation.

### ⏱️ Response Timeline
- **Acknowledgment:** Within 48 hours.
- **Triage:** Within 7 days.

## 🤝 Responsible Disclosure Guidelines
1. No unauthorized data access.
2. No service disruption (DoS).
3. Confidentiality during the patch window (90 days).
